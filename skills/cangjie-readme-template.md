## 写 README 的几条经验

| 经验 | 说明 |
|---|---|
| 安装步骤要在干净环境可复现 | 尤其 `envsetup.sh` 这类前置步骤，漏了别人第一步就卡住 |
| 快速上手用最短命令 | 能复制粘贴就跑起来，别让人读三段配置才能试 |
| 测试命令要区分根包与子包 | 根目录 `cjpm test` 不进入 `libs/*` 子包 |
| 版本号与 `cjpm.toml` 保持一致 | README 里出现的版本号要有唯一来源 |
