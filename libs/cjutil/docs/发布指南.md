# cjutil 独立仓库发布指南

cjutil 已自包含，可作为独立库贡献仓颉生态。

## 仓库结构（已就绪）

```
cjutil/
├── src/                    # 源码
├── examples/demo/          # 最小示例（cjpm build + 运行）
├── README.md               # 库文档（API 概览 + 快速开始）
├── LICENSE                 # MIT
├── .github/workflows/      # CI 模板（发布时移到仓库根）
└── cjpm.toml               # 包定义（version 0.1.0）
```

## 发布步骤

1. **建独立仓库**：推送到 atomgit（推荐 Cangjie-TPC 组织或自建，命名 `cjutil`）
2. **移动 CI**：`.github/workflows/build.yml` 移到新仓库根（GitHub Actions 只认仓库根），配好仓颉 SDK 安装步骤（见 workflow 注释）
3. **打 tag**：`cjpm.toml` version 0.1.0，发布后 `git tag v0.1.0`
4. **提交中心仓**（可选）：按 pkg.cangjie-lang.cn 发布流程提交，用户可 `cjutil = "0.1.0"` 直接依赖
5. **向 SIG 请求收录**（可选）：Cangjie-TPC / Cangjie-SIG 审核后收录官方组织

## 依赖说明

**仅官方 stdx**（net.http/crypto/encoding.json）——stdx 是华为官方扩展库，非第三方。

## 与 cjh 主仓库同步

- 源码演进在 cjh 仓库 `libs/cjutil/`，独立仓库作为发布镜像
- 每次改动：cjh 提交 → 同步独立仓库 → 打新 tag
