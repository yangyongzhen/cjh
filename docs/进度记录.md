### 关键修复（踩坑沉淀）
9. **RPATH**：产物内嵌 DT_RPATH（--disable-new-dtags），./main 无需 LD_LIBRARY_PATH
10. **TLS**：ClientBuilder 需 tlsConfig(TlsClientConfig())，修复 "TLS must be configured"
11. **流式工具调用**：delta.tool_calls（在 choices[0].delta 内非顶层）
12. **base_url 自动补全**：OpenAI /v1/chat/completions、Anthropic /v1/messages
13. **provider 劫持**：只有显式 CJH_PROVIDER=anthropic 才用 Anthropic（不再被 env 劫持）
14. **中文 mojibake 根治**（多轮）：
    - 迭代 String 得 Byte（非码点）→ truncateLine/mock 不用 Rune(byte) 重建
    - takeDelta 字节切片 → 全文比对（lastSentText）
    - **DeepSeek 服务端自身返回 mojibake**（"你好"→"ä½\xa0å¥½"）→ MojibakeFix
      解码修复；hasCjk 判定曾用 Byte 迭代恒 false → 改 toRuneArray
    - **流式分片切碎 mojibake 根治**：feed() 只累积原始文本，finish() 对完整串
      整体 MojibakeFix.fix（逐 chunk 修复在分片切碎乱码串时必失败）；
      TUI 新增 streamStartPos + endStream() 用修复后完整文本整体重绘替换流式段
      （onAssistantText 改为 endStream(md.process(text)+md.finish())）
15. **中文 IME 输入**：readKey 支持多字节 UTF-8，handleKey 接受任意字符
16. **中文退格崩溃**：Backspace 按字符删除（字节安全回退）
17. **输入焦点丢失**：appendDelta 跨线程直接 render 竞态 → 只 markDirty + renderLock

### UI 打磨
18. **logo**：box-drawing CJ → ASCII art "CJ"（C 蓝+J 青+3 空格分隔，消除 CI 误读）
19. **布局**：logo 区 → 标题栏（含模型徽章）→ 分隔线 → 输出区 → 状态徽章 → ❯ 输入行
20. **配色**：回复默认白、工具调用绿、参数灰、错误红、输入提示亮青（参考 omp）
21. **markdown 高亮**：MarkdownRender 流式渲染（**粗体**/`行内代码`/```代码块```）
22. **会话分隔**：每轮回复后淡色分隔线；用户消息 ❯ 前缀（去 cjh>）
23. **stderr 屏蔽**：Stderr.suppress/restore，TUI 全屏模式不污染屏幕
